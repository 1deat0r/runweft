# Security policy

Runweft is currently a scaffold. It does not provide a scheduler, durable runtime,
broker, provider execution, or security sandbox. Do not use it to execute sensitive
or production work.

## Reporting a vulnerability

Report suspected vulnerabilities through GitHub's private vulnerability reporting
for this repository: <https://github.com/1deat0r/runweft/security/advisories/new>.
Do not post exploit details, credentials, or sensitive data in a public issue or PR.

The maintainer will acknowledge reports when available and coordinate a fix and
disclosure. There is no service-level response-time commitment. Security claims
must be tied to the tested artifact and evidence; passing scaffold checks is not a
runtime security assessment.
