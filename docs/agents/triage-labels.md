# Triage labels

When a GitHub Issue is being triaged, use the default Matt Pocock state labels:

| Role | Label |
| --- | --- |
| needs triage | `needs-triage` |
| needs more information | `needs-info` |
| ready for an agent | `ready-for-agent` |
| ready for a human | `ready-for-human` |
| will not be fixed | `wontfix` |

Use one category label (`bug` or `enhancement`) and one state label per triaged
Issue. These labels organize the optional backlog; they do not make an Issue or PR
mandatory for routine development, and they do not authorize implementation. When
the user asks to triage an Issue, follow the installed triage skill, including its
AI-generated comment disclosure. Keep vulnerability details private.
