# Provenance

Created 2026-09-28 for the user's Runweft successor project. New scaffold code and
specification were authored for this project. No OmO implementation or prompt
assets were copied. The cited OmO baseline is commit
`713775cedd533d00c2048ec6dc677f942f3b2ad0` (manifest 5.0.1).

`docs/research/` preserves the previously authored design and its original board
record as historical input. `docs/architecture/` preserves the generated Archify
logical map and receipts byte-for-byte; receipt absolute paths name its original
generation location, while hashes bind the copied bytes. This does not constitute
fresh visual or interaction testing of a product inspector.

`evals/analyze_evaluation.py` is the earlier independently authored EP1 analysis
script, renamed only for Python conventions. EP1 governs future experiments;
its fixture manifests do not exist yet. No benchmarks have been run.
The project copy of `docs/evaluation-protocol.md` updates only document references
and the script filename; its original sampling/analysis/decision rules are unchanged.

Registry-resolved dependencies are pinned in lockfiles and keep their licenses.
The Apache-2.0 project license does not relicense dependencies or the cited OmO repository.
